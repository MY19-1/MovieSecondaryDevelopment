# 电影购票系统（二次开发）

## 一、项目简介

本项目基于开源 Java Web 电影购票系统进行学习与二次开发，主要用于学习传统 Java Web 项目的运行原理、业务逻辑及前后端交互。

在原有项目基础上，尝试接入了第三方API获取实时电影数据，增加验证码功能，并进行了修复和维护

本项目目前处于持续学习与开发阶段。

## 二、技术栈

- **后端：** Java、Spring MVC、MyBatis
- **数据库：** MySQL
- **Web 容器：** Apache Tomcat
- **项目构建：** Maven
- **前端：** JSP、JavaScript、jQuery、Ajax
- **第三方接口：** The Movie Database（TMDB）API
- **版本管理：** Git、GitHub

## 三、主要功能

- 用户注册与登录
- 邮箱验证码发送与验证
- 电影信息展示
- 电影数据查询与处理
- 管理员相关功能
- 第三方电影数据 API 接入与学习

注：具体功能以当前项目实际实现情况为准，部分功能仍在完善中。

## 四、项目运行环境

- JDK 8
- Apache Tomcat 9
- MySQL
- Maven
- IntelliJ IDEA 或其他支持 Java 的 IDE

## 五、本地运行说明

1. 克隆或下载本项目。
2. 使用 IDE 等导入项目，并等待 Maven 依赖加载完成。
3. 在本地 MySQL 中创建数据库，并根据项目实际情况导入数据库 SQL 文件。
4. 在本地配置数据库连接信息。
5. 配置项目所需的邮箱服务参数及第三方 API 参数。
6. 配置 Tomcat 并启动项目。

## 六、第三方服务说明

本项目使用了 The Movie Database（TMDB）API 获取电影相关数据。

This product uses the TMDB API but is not endorsed or certified by TMDB.

TMDB 官网：https://www.themoviedb.org/
